# tooling/debt

The deterministic half of the tech-debt program: package graph, debt scan,
metrics, baseline and gate. Judgment lives in `.claude/agents/debt-*.md`.

- No dependency on a product package, ever. `turbo boundaries` denies the
  `tooling` tag the `product` tag. The only devDependencies are the ESLint
  config and `@vitest/coverage-v8`.
- Runs as TypeScript under Node's native type stripping: erasable syntax only
  (`erasableSyntaxOnly` in `tsconfig.json`), `#src/*` imports, JSON via
  `readFileSync`. No build step.
- `baseline/` is generated by `pnpm debt baseline` and never hand-edited. CI
  regenerates it and fails on a diff; the `debt-baseline-guard` hook refuses
  editor writes.
- Rules are data in `debt.config.json`. A new line rule is one entry plus a
  case in `src/scan/scan.test.ts`. A file rule needs code in `src/scan/scan.ts`.
- Graduation: a category at zero across every package becomes an ESLint error
  in `packages/eslint-config/base.js` and leaves the config.
- `.out/` is scratch (gitignored). Tests build temp workspaces under
  `mkdtemp`; nothing under `tooling/` is scanned.
- Explanations go in `README.md` and `debt.config.json` `why` fields, not in
  code comments (two-line cap applies here too).
